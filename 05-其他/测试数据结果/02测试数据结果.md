# **推免资格概率评估与升学规划报告**

- **专业总人数：** 200
- **当前排名比例：** 前32.0%

- **英语情况：** CET-4、CET-6成绩尚未提供。

- **其他重要信息：** 挂科、重修、处分及学术诚信情况尚未提供。

## **二、学校推免资格核验结果**

1. **学校核验：** 中国科学技术大学真实存在，是教育部认可的具有推荐优秀应届本科毕业生免试攻读研究生资格的高校。
2. **学校政策：** 学校已确认推免工作由研究生招生工作组统筹，各学院负责制定具体的指标分配、推荐和接收办法。基本条件包括思想品德合格、无挂科记录、GPA不低于2.5、体测达标等。
3. **学院/专业政策：** **尚未确认。** 未能检索到软件工程专业所属学院的官方推免实施细则，这是当前评估的最大不确定性来源。
4. **已确认硬性条件：** 无挂科记录是明确要求。

## **三、当前保研机会评估**

**综合保研概率：65%**

**明确结论：机会存在但需明确学院细则并提升排名**

**概率主要依据：**

1. **学校整体环境优越：** 学校整体历史保研率（参考区间50%-60%）处于全国顶尖水平，为学生提供了良好的宏观环境。当前排名前32%处于该宏观区间内。
2. **排名是关键变量：** 前32%的排名是当前评估的核心依据。在保研率较高的学校，此排名具备争取资格的现实可能性，但并非绝对安全。
3. **学院差异是最大未知数：** 概率评估主要依赖学校整体数据，未考虑学院或专业的具体名额分配。若软件工程专业或所属学院保研率低于学校平均水平，则实际机会将降低；反之则可能增加。
4. **个人条件尚不完整：** 英语成绩、GPA、有无挂科等关键硬性条件尚未提供，存在潜在风险。当前按“满足基本要求”进行中性估算。

**当前最大优势：** 身处保研率极高的顶尖学府（中国科学技术大学）。 **当前最大短板：** 专业排名（前32%）在学校高保研率背景下有竞争力，但不够突出；且缺乏学院级具体政策的指引。 **当前所处竞争位置：** 处于学校整体保研资格竞争范围的**边缘至中后段**，需要稳住并争取提升排名。

## **四、当前排名与政策门槛的差距**

- **当前排名与比例：** 第64名，前32.0%。
- **参考推免比例：** 暂未获得软件工程专业的可靠推免比例。参考学校整体历史保研率区间为 **50%-60%**（数据层级：学校整体，源自多个非官方数据源交叉验证，可靠性中等）。
- **差距分析：**
- 若以学校整体保研率下限（50%）为参考，对应专业前100名。学生当前第64名，**领先约36名**，处于相对安全的位置。
- 若以学校整体保研率上限（60%）为参考，对应专业前120名。学生当前第64名，**领先约56名**，优势更为明显。
- **重要提示：** 以上是基于学校整体数据的推算。实际专业或学院保研率可能不同，这是评估中的核心不确定性。学生亟需核实所在学院的具体比例。

## **五、额外加分校验**

学生当前无额外加分经历，竞赛、科研等经历也尚未提供。根据学校政策，科研潜质是考察因素之一，竞赛、科研等成果在学院制定的细则中通常具有积极作用，但具体加分分值需以所在学院对应届次正式推免实施细则为准。

## **六、当前主要风险**

1. **排名波动风险：** 大二仍有大量专业核心课程，当前排名可能因后续课程成绩发生较大变化。下滑至前40%以外将显著降低机会。
2. **学院政策不明风险：** 学院可能设有高于学校的基本要求（如更高GPA、特定英语分数线、核心课程成绩要求），或专业保研率低于学校平均水平。
3. **硬性条件缺失风险：** GPA是否≥2.5、有无挂科、英语六级是否达标等关键信息未知，任何一项不满足都可能直接失去资格。
4. **综合竞争力不足风险：** 在排名相近的竞争中，缺乏有分量的竞赛、科研或项目经历，可能在综合评定中处于劣势。

## **七、想争取保研应该怎么做**

**保持底线：** 确保所有课程不挂科，GPA维持在2.5以上，尽早通过英语六级（目标450+）。 **推荐目标：** 将专业排名提升至**前25%**（约第50名以内）。 **冲刺目标：** 将专业排名提升至**前20%**（约第40名以内）。

**具体建议：**

1. **学习为本：** 聚焦当前学期及后续专业核心课程，争取高分。这是提升排名最直接、最有效的方式。
2. **英语攻坚：** 立即准备并报名大学英语六级考试，争取一次通过并获得理想分数（如500分以上），以满足潜在的高要求。
3. **竞赛/科研入门：** 开始关注并尝试参与适合大二学生的竞赛（如ACM-ICPC、数学建模、软件创新大赛）或联系导师进入实验室参与基础科研项目，积累经历。
4. **政策准备：** **立即行动**，通过学院官网、教务处、咨询学长学姐等渠道，务必查明：(a)软件工程专业所属学院；(b)该学院近2-3年的官方推免实施细则；(c)近年的实际推免名额和学生基数。

## **八、分阶段升学规划**

**大二下学期 → 大三上学期 → 大三推免关键阶段**

- **当前阶段（大二下）：**
- **学习目标：** 全力学好本学期课程，争取核心课程90+。
- **排名目标：** 稳住前32%，力争进入前30%（第60名）。
- **英语任务：** 通过CET-6考试。
- **竞赛/科研任务：** 选择1-2项竞赛或科研项目开始参与。
- **政策准备：** 完成对学院推免细则的初步调研。
- **大三上学期：**
- **学习目标：** 继续保持高绩点，核心课程成绩是关键。
- **排名目标：** 达到推荐目标（前25%，约第50名）。
- **英语任务：** 如成绩不理想可刷分。
- **竞赛/科研任务：** 争取在竞赛中获得省级以上奖项，或形成初步的科研产出（如实验报告、项目代码）。
- **政策准备：** 深入研究学院细则，明确加分项，规划大三下的冲刺方向。
- **大三下学期及暑假（推免关键期）：**
- **学习目标：** 完成所有课程，确保最终排名达到冲刺目标（前20%）。
- **综合准备：** 整理所有奖项、证明，准备个人简历、陈述，关注目标院校夏令营信息。

1. **核心数据缺失：** 本报告评估所依赖的保研率（50%-60%）为学校整体数据，非软件工程专业或所属学院的精确数据。专业实际推免率可能高于或低于此区间。
2. **政策细则未知：** 学院层面的推免实施细则（包括排名计算方式、英语硬性要求、竞赛科研具体加分规则）完全未知，这对精准定位影响巨大。
3. **个人条件未明：** 学生的GPA、英语成绩、有无挂科等关键硬性条件尚未提供，存在不满足基本要求的风险。
4. **未来变量：** 学生后续排名可能变化，学校及学院政策每年可能微调。
